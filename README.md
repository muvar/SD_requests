# Система отслеживания заявок (Ticket Tracker)

Мобильное приложение для отслеживания и управления заявками пользователей, разработанное на .NET MAUI с использованием MS SQL Server.

## Описание

Приложение предназначено для управления заявками в организации и поддерживает четыре роли пользователей:

### Роли пользователей

1. **Оператор** - создание и редактирование заявок
   - Создание новых заявок
   - Редактирование собственных заявок
   - Закрытие заявок
   - Просмотр истории заявок

2. **Специалист** - управление заявками
   - Просмотр всех заявок
   - Добавление комментариев
   - Назначение исполнителей
   - Закрытие заявок
   - Просмотр истории изменений

3. **Исполнитель** - выполнение заявок
   - Просмотр назначенных заявок
   - Добавление комментариев
   - Изменение статуса заявки
   - Завершение заявок со статусом "Выполнено" или "Отложено"
   - Просмотр истории заявки

4. **Администратор** - управление пользователями
   - Создание новых пользователей
   - Выдача логинов и паролей
   - Назначение ролей
   - Активация/деактивация пользователей
   - Сброс паролей

## Технологии

- **.NET MAUI** - кроссплатформенная мобильная разработка
- **C#** - язык программирования
- **MS SQL Server** - база данных
- **Entity Framework Core** - ORM для работы с базой данных
- **MVVM Pattern** - архитектурный паттерн
- **CommunityToolkit.Mvvm** - библиотека для MVVM
- **BCrypt.Net** - хеширование паролей

## Требования к системе

### Для разработки:
- Visual Studio 2022 (версия 17.8 или выше)
- .NET 8.0 SDK
- MS SQL Server (LocalDB, Express или полная версия)
- Android SDK (для Android разработки)
- Xcode (для iOS разработки, только на macOS)

### Для запуска:
- Android 7.0 (API level 24) или выше
- iOS 11.0 или выше
- MS SQL Server с доступом к базе данных

## Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd TicketTracker
```

### 2. Настройка базы данных

#### Создание базы данных:
1. Откройте SQL Server Management Studio
2. Выполните скрипт `Database/CreateDatabase.sql`
3. Выполните скрипт `Database/SeedData.sql` для добавления тестовых данных

#### Настройка строки подключения:
Отредактируйте файл `appsettings.json`:
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=TicketTrackerDB;Trusted_Connection=true;TrustServerCertificate=true;"
  }
}
```

### 3. Сборка и запуск

#### В Visual Studio:
1. Откройте `TicketTracker.sln`
2. Выберите целевую платформу (Android/iOS)
3. Нажмите F5 для запуска

#### Из командной строки:
```bash
# Для Android
dotnet build -f net8.0-android
dotnet run -f net8.0-android

# Для iOS (только на macOS)
dotnet build -f net8.0-ios
dotnet run -f net8.0-ios
```

## Функциональность

### Система аутентификации
- Вход по логину и паролю
- Автоматическое перенаправление на соответствующую роли страницу
- Безопасное хранение паролей (BCrypt)

### Управление заявками
- Создание заявок с приоритетом
- Назначение исполнителей
- Отслеживание статуса заявок
- Система комментариев
- Полная история изменений

### Интерфейс
- Адаптивный дизайн для мобильных устройств
- Интуитивно понятный пользовательский интерфейс
- Разные интерфейсы для каждой роли

## Безопасность

- Хеширование паролей с использованием BCrypt
- Проверка прав доступа на уровне сервисов
- Валидация входных данных
- Защита от SQL-инъекций через Entity Framework
